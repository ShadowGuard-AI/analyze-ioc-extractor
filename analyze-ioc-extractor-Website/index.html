The Sluice Run

Extracts Indicators of Compromise (IOCs) such as IP addresses, URLs, and email addresses from a text file or standard input, using regular expressions. A sluice washes a whole stream of gravel through and keeps only the few heavy pieces that settle; this tool washes a file of text through its patterns and keeps only the indicators.

What it does

The extractor reads a text file, or standard input, and pulls out the indicators hiding in it: IP addresses, URLs, email addresses, MD5, SHA1 and SHA256 hashes, and domains. Usage, as the README gives it: python3 main.py [INPUT] [-o OUTPUT] [-i IOC_TYPE] [-v] [-q]. Its one requirement is pandas>=2.1.0.

Verified behavior

A sample containing an IP address, a URL, an email address, an MD5 hash, and a domain produced rows for each of those types. With -i ip, only the IP row was produced. With -o, the CSV has two columns, ioc_type and ioc_value. Reading from stdin with - works.

Stated limits
